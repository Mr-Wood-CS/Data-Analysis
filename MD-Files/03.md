# Lesson 3: Filtering records

**Time:** 45 minutes · **Skills:** Boolean masks with >, < and ==

## Learning intention

## Key idea

A comparison creates one True/False value per row. Putting that mask inside df[...] keeps True rows. Demonstrate score > 80; test the boundary value 80 on paper. Python uses == for comparison and = for assignment.

## Worked model

The starter has already loaded `gaming.csv` as `df`, imported Pandas as `pd`, and defined the output folder `OUT`. Chart starter scripts also import `plt`.

```python
mask = df["score"] > 80
print(mask.head())
selected = df[mask]
print(selected[["player_id", "score"]])
print("Records", len(selected))
```

Before running: predict one output. After running: explain one line to your partner. Python field names and game labels must match exactly.

## Your investigation

1. Predict whether a score of exactly 80 is selected, then test your explanation against the table.

2. Select players scoring at least 80. Display player_id and score.

3. Select the records for Block Quest. Count them and explain the comparison operator.
