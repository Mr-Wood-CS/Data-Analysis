## Key idea

A CSV stores a table as text. A record is one row; a field is one column. Here one record is a fictional player summary, not a single match. player_id is a unique identifier. A DataFrame is Pandas’ table structure. Show import, the variable df, a function call and the dot in df.head(). Explain that df is a chosen variable name.
