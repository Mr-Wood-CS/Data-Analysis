## Key idea

value_counts() counts occurrences of each value. A category count is not a mean score. normalise counts to proportions and multiply by 100 for percentages. Equal category sizes here are a feature of made-up teaching data.

## Worked model

The starter has already loaded `gaming.csv` as `df`, imported Pandas as `pd`, and defined the output folder `OUT`. Chart starter scripts also import `plt`.

```python
counts = df["game"].value_counts()
print(counts)
print("Percent", df["game"].value_counts(normalize=True).mul(100).round(1))
```

Before running: predict one output. After running: explain one line to your partner. Python field names and game labels must match exactly.
