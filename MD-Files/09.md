A clear title describes the fictional sample; labels explain units. The scripts save PNG files so they work without a pop-up window.

## Worked model

The starter has already loaded `gaming.csv` as `df`, imported Pandas as `pd`, and defined the output folder `OUT`. Chart starter scripts also import `plt`.

```python
counts = df["game"].value_counts().sort_index()
ax = counts.plot.bar(color="steelblue", rot=15)
ax.set(title="Games in the fictional club sample", xlabel="Game", ylabel="Players (count)")
ax.set_ylim(bottom=0)
plt.tight_layout()
plt.savefig(OUT / "lesson09_games.png")
plt.close()
print(counts)
```

Before running: predict one output. After running: explain one line to your partner. Python field names and game labels must match exactly.
